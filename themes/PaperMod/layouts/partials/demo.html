Demo Video

This video demonstrates the process of running UnitCon on an example program.
The example program is the Main program inside the test directory. Line 11 of the Main.java file in this program is the target location. By executing UnitCon's build, analyze, and synthesize commands in order, you can synthesize a unit test case that triggers the target error.
If UnitCon successfully synthesizes a unit test case that triggers the target error, it returns the location of the generated test file and the command to run it. Then, you can run it!
